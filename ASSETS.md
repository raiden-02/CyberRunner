# Assets

Source code is ISC. See `LICENSE`.

Shipped presentation is generated by this project. There are no third-party models, skyboxes, or audio files in `client/public`.

## Generated at runtime

| Surface | Source |
|---------|--------|
| Weapon meshes | `client/src/weapons/weapon-viewmodel.ts` and `procedural-kit.ts`. Built from boxes, cylinders, and cones. |
| Shoot House skybox | `client/src/world/Skybox.ts`. Six canvas faces, dark cyan night gradient. |
| Gunshots and footsteps | `client/src/audio/AudioManager.ts`. Short synthesized buffers. Missing weapon families fall back to the generic shot. |

UI click, reload, and hit-marker helpers exist on `AudioManager` but have no clip. Those calls no-op.

## Not shipped

Earlier unverifiable glTF weapons, cubemap PNGs, and `.wav` / requested `.ogg` files were removed. They were not needed for gameplay. Weapon IDs, damage, fire rate, ammo, and network behavior did not change.
